
HERETIC · KoloBokPove$ilsa Studio

Мультичат-мост для генерации аниме-артов:
LLM-арт-директор -> ComfyUI -> VLM-критик.

Основная идея проекта:
языковая модель выступает арт-директором, генерирует промпты для
Illustrious XL / SDXL, ComfyUI рисует кадры, а затем та же самая
языковая модель осматривает готовую картинку и выносит вердикт.

В моем случае: r5 5600, 48gb ram, cmp90hx 10gb, rtx3070ti 8gb
Для модели в Lm studio нужно включить 
llama.cpp Arguments Override (находится в конце списка в Load model).
Пролистать вниз
добавить аргумент --chat-template-file
в соседнее поле вписать путь к nothink.jinja (...heretic-bridge\nothink.jinja)

=====================================================================
1. АРХИТЕКТУРА
=====================================================================

Компоненты:

1. Арт-директор
   Модель:
   Qwen3.5-9B-Ultra-Uncensored-Heretic-Q6_K

   Где работает:
   LM Studio, GPU 0, порт 1234

   Задача:
   - понимает запрос пользователя;
   - задаёт уточняющие вопросы;
   - пишет план серии;
   - генерирует danbooru-промпты;
   - правит промпты по замечаниям;
   - переписывает промпт после критики.

2. Генератор изображений
   Движок:
   ComfyUI

   Где работает:
   GPU 1, например RTX 3070 Ti, порт 8188

   Задача:
   - генерация базового кадра;
   - HiRes Fix;
   - апскейл;
   - финальное сохранение изображения.

3. VLM-критик
   Модель:
   Qwen3.5-9B-Ultra-Uncensored-Heretic-Q6_K

   Важно:
   В роли зрительного критика выступает ТА ЖЕ САМАЯ модель:
   Qwen3.5-9B-Ultra-Uncensored-Heretic-Q6_K.

   Отдельная VLM не требуется.
   Модель получает изображение через мультимодальный вход LM Studio
   и возвращает описание, вердикт и список дефектов.


=====================================================================
2. КАК ЭТО РАБОТАЕТ
=====================================================================

Пользователь пишет сцену или тему.

Дальше мост делает примерно следующее:

1. Получает запрос пользователя.
2. Если нужно, задаёт уточняющие вопросы.
3. Формирует план серии.
4. Пишет промпты английскими danbooru-тегами.
5. Отправляет промпт в ComfyUI.
6. ComfyUI генерирует базовый кадр.
7. При включённом HiRes делает апскейл и повторный денойз.
8. Сохраняет финальный кадр.
9. Отправляет картинку в VLM-критик.
10. Критик осматривает кадр:
    - анатомия;
    - соответствие замыслу;
    - стиль;
    - фон;
    - свет;
    - композиция;
    - дефекты.
11. Если найдены критичные дефекты, мост может один раз
    переписать промпт и сделать ретрай.
12. После этого формируется оценка и сохраняется результат.


=====================================================================
3. ОСОБЕННОСТИ
=====================================================================

- Мультичат.
  Можно вести несколько независимых диалогов.

- Уточняющие вопросы.
  Модель может задать 10-30 вопросов с вариантами ответов.

- Серия кадров.
  За один запрос можно сгенерировать несколько изображений.

- Режим правки.
  Можно попросить исправить конкретный кадр:
  "убери очки", "сделай ночь", "камера ближе" и т.д.

- Прямой режим.
  Можно прислать готовый промпт и сказать использовать его как есть.

- Режим без вопросов.
  Можно попросить сразу генерировать без уточнений.

- VLM-критик.
  Автоматический осмотр изображения.

- Ретрай при браке.
  Если критик считает кадр бракованным, мост может переписать
  промпт и повторить генерацию.

- HiRes Fix.
  Двухпроходная генерация с апскейлом и повторным денойзом.

- LoRA.
  До 10 слотов с индивидуальными весами.

- Телеметрия.
  Температура, загрузка, RAM, VRAM и потребление в ваттах.

- Прогресс шагов.
  Прогресс генерации получается через WebSocket ComfyUI.

- Идеи.
  Есть кнопки со стартовыми идеями и генерация новых идей через LLM.

- Память.
  Сохраняются саммари прошлых работ, последние кадры, дефекты,
  оценки и история генераций.


=====================================================================
4. ТРЕБОВАНИЯ К ЖЕЛЕЗУ
=====================================================================

Рекомендуется:

- Два GPU.
- GPU 0: минимум 12 ГБ VRAM для LLM/VLM-критика.
- GPU 1: минимум 8 ГБ VRAM для SDXL / Illustrious XL.
- RAM: желательно 32 ГБ и больше.

Пример разделения:

- GPU 0: Qwen3.5-9B-Ultra-Uncensored-Heretic-Q6_K через LM Studio.
- GPU 1: ComfyUI для генерации изображений.

5. ТРЕБОВАНИЯ К ПРОГРАММАМ
=====================================================================

1. Python 3.10 или новее.

2. LM Studio.
   Адрес:
   http://127.0.0.1:1234

   В ней должна быть загружена модель:
   Qwen3.5-9B-Ultra-Uncensored-Heretic-Q6_K

   Желательно, чтобы LM Studio использовала только GPU 0.

3. ComfyUI.
   Адрес:
   http://127.0.0.1:8188

   Пример запуска:
   python main.py --cuda-device 1 --highvram

4. nvidia-smi должен быть доступен в системе.
   Он нужен для телеметрии.

5. Желательно установить LibreHardwareMonitor или
   OpenHardwareMonitor для получения температуры и мощности CPU.

=====================================================================
9. РЕЖИМЫ РАБОТЫ
=====================================================================

Режим 1: Новая тема
--------------------

Пользователь описывает сцену.

Модель задаёт уточняющие вопросы.
Пользователь отвечает кликами или текстом.
После этого запускается генерация.


Режим 2: Правка кадра
--------------------

Если уже есть последний кадр, сообщение воспринимается как правка.

Примеры:
- убери очки;
- сделай ночь;
- волосы длиннее;
- камера ближе;
- без куртки;
- добавь дождь;
- мрачнее.

Модель сохраняет основу старого промпта и меняет только нужные
теги. Если нужно, сохраняет тот же seed.


Режим 3: Прямой промпт
--------------------

Можно прислать готовый промпт в тегах.

Примеры фраз:
- используй этот промпт;
- ничего не меняй;
- вот промпт;
- с этим промптом.

Тогда мост использует промпт почти без изменений.


Режим 4: Без вопросов
--------------------

Можно попросить модель не задавать вопросы.

Примеры фраз:
- без вопросов;
- просто сгенерируй;
- не спрашивай;
- генерируй сразу.

11. НАСТРОЙКИ В ВЕБ-ИНТЕРФЕЙСЕ
=====================================================================

Можно менять:

- чекпоинт;
- разрешение генерации;
- финальный размер после апскейла;
- апскейлер;
- шаги;
- CFG scale;
- количество картинок в серии;
- включение или отключение VLM-критика;
- LoRA-слоты;
- пресеты качества.

Пресеты:

Черновик
Быстрая генерация с меньшим числом шагов.

Финал
Сбалансированный режим.

Максимум
Больше шагов и выше требования к качеству.

=====================================================================
14. ВАЖНЫЕ ЗАМЕЧАНИЯ
=====================================================================

1. Разделение GPU обязательно.
   Нельзя сажать и LM Studio, и ComfyUI на одну и ту же
   видеокарту, если памяти недостаточно.

2. Критик использует ту же модель.
   Отдельный ммпроект не нужен, если критик работает через
   LM Studio.

3. NSFW поддерживается.
   Модель может писать прямые теги без эвфемизмов, если тема
   этого требует.

4. Промпт строится по блокам.
   Сначала персонаж, потом тело, волосы, глаза, одежда, поза,
   камера, фон, свет, стиль.

5. Отрицательные теги идут в negative.
   В позитивном промпте не должно быть слов вроде
   "no", "without" и похожего мусора.
